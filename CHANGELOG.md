## Upload size limit (server-side, not in this repo)

nginx on the production host sits in front of the container on port 8000 and enforces its own request-body cap. Its default is **1 MB**, which silently rejects large bulk workbooks with a `413` before the backend ever sees them. This is not configured anywhere in this repo — it lives only in the host's nginx site file, so it survives `git pull` + rebuild and must be set by hand once:

```nginx
# inside the server { } block for reportgenetics.andrsn.in
client_max_body_size 100M;
```

Then `sudo nginx -t && sudo systemctl reload nginx`.

Neither uvicorn nor FastAPI imposes a body-size limit of its own, so nginx is the only ceiling.
